# Patreon verification

Patreon verification requires a valid creator OAuth grant, stable creator or campaign ID, and canonical public page where the official API permits. Missing credentials, scopes, grants, or authoritative campaign identity produce unavailable, needs-attention, or pending states. AudienceOwn does not scrape Patreon.

Patron lists, pledge amounts, earnings, recipient data, and private tiers are never stored. Verification does not promise benefit delivery.
