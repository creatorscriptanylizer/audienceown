# Provider Expansion II

Stage 8.3 adds TikTok creator identity and Display API video polling, Instagram professional-account media detection, and Facebook Page post detection. It extends the existing OAuth, encrypted-secret, normalized detection, approval-first draft, identity, trust, monitoring, authenticity, and ecosystem systems.

Automatic provider publishing, emergency activation, follower delivery, scraping, audience data, comments, messages, and engagement-based trust are outside this stage. Every provider retains a constrained public-URL import and verification fallback.

Production readiness is derived from credentials, product setup, stored grants, selected-asset authority, and app-review state. Review defaults to `not_configured`. The worker is `POST /api/internal/providers/expansion-two/sync`; health is `GET /api/internal/providers/expansion-two/health`.
