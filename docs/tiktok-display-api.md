# TikTok Display API

The adapter requests at most 20 public videos per cursor page and runtime-validates the official response. A video requires a stable ID, API creation time, and canonical TikTok share URL. Cover, embed, duration, and dimensions are optional operational metadata. Comments, viewers, engagement, private videos, drafts, Research API data, and scraped data are not read.

If credentials, product configuration, `video.list` review, or the user grant is missing, identity may remain connected while automatic detection is unavailable. Manual URL import remains available.
