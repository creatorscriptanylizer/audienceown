# Instagram integration

Automatic support is limited to professional Business and Creator accounts. The stable professional account ID anchors identity while username changes preserve continuity. Official media polling accepts image, video, carousel, and reel objects with stable IDs, authoritative timestamps, and canonical permalinks.

Personal accounts, comments, DMs, followers, insights, and login-protected scraping are unsupported. Expiring media URLs are never treated as durable public identity evidence. Every media object creates at most one approval-required draft; publishing is disabled.
