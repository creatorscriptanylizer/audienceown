# TikTok manual fallback

Manual import accepts only canonical HTTPS `tiktok.com/@handle/video/{numeric-id}` URLs, a creator title, and a creator-supplied publication timestamp. It creates an unverified `manual_import` detection and one approval-required draft. It does not prove ownership or improve trust.

Ownership fallback requires an expiring hashed challenge in an exact public bio/post placement, verified creator-domain linkage, signed AudienceOwn manifest, or constrained operator review. A profile URL alone is never verification.
