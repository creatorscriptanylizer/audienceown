# Spotify integration

Spotify Authorization Code OAuth anchors the immutable Spotify account ID and synchronizes only display name, public URL, image, availability, and token health. It requests no listening, library, top-item, playback, or write scopes. Artist detection is unavailable without authoritative creator-asset access. Show episodes are eligible only after linkage to an AudienceOwn-verified canonical feed and are reconciled to that feed so one canonical episode creates one draft. Audio is never downloaded and artwork remains unmodified with Spotify attribution.
