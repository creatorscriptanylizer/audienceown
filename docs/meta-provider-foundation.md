# Meta provider foundation

Facebook Login authorizes one Meta app user only for asset discovery. AudienceOwn discovers managed Pages, filters for sufficient Page tasks, shows linked professional Instagram accounts, and requires explicit selection. Each selected asset gets its own provider connection, stable asset binding, content source, and encrypted asset-bound credential.

The app user, Page, linked Instagram professional account, Page token, app-scoped IDs, and public handles remain distinct. Page credentials cannot act for another Page. Only safe labels and canonical links reach creator/public serializers.
