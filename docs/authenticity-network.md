# Authenticity Network

Safe ecosystem lifecycle events extend public feeds and webhooks using canonical public links only. Provider evidence, permissions, membership records, stable IDs, and operational errors stay private.

Stage 7.1 makes the existing AudienceOwn authenticity projection portable. AudienceOwn remains the sole issuer; manifests, lookups, continuity proofs, feeds, SDK verification, and webhooks never become identity evidence or propagate trust. Public outputs inherit Stage 7.0 restriction, monitoring, emergency, and revocation policy.

Discovery begins at `/.well-known/audienceown-network.json`. Current-state resources use short caches or `no-store`; historical continuity records expose revoked and superseded state. Network features do not activate emergencies or send follower notifications.
