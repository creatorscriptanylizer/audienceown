# Snapchat integration

Login Kit uses Authorization Code OAuth with app-specific external ID, display name, and optional Bitmoji only. Contacts, friends, messages, Memories, private content, and general Story history are out of scope. Public Profile API support is a separate business authorization and allowlist-gated capability; access defaults to `not_configured`. Automatic public-content detection remains unavailable unless the approved API provides durable official URLs and timestamps.
