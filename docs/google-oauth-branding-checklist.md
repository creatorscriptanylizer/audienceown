# Google OAuth branding checklist

Use the production Google Cloud project. Never place client secrets, reviewer credentials, or verification tokens in this repository.

- App name: **AudienceOwn**
- Homepage: <https://audienceown.com>
- Privacy policy: <https://audienceown.com/privacy>
- Terms: <https://audienceown.com/terms>
- Data deletion: <https://audienceown.com/data-deletion>
- Support email: **support@audienceown.com** (verify and monitor before submission)
- Developer contact: **contact@audienceown.com** (verify and monitor before submission)
- Authorized domain: **audienceown.com**
- Logo: square, high-resolution, transparent or clean background, consistent AudienceOwn branding, and no misleading Google or YouTube marks
- Audience: External; publishing status prepared for Production
- YouTube scope: `https://www.googleapis.com/auth/youtube.readonly` only
- Google authentication scopes, in the separate sign-in flow: `openid`, `email`, `profile`

Confirm the app name, homepage, policies, consent-screen identity, and redirect domains all match exactly. Legal and contact copy requires owner and qualified-counsel review before launch.
