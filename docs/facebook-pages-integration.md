# Facebook Pages integration

Stage 8.3 supports explicitly selected managed Facebook Pages only. Page discovery requires suitable official Page tasks and an asset-bound encrypted Page credential. Stable Page ID anchors identity; Page name and username changes preserve it. Authority loss, token revocation, or unpublished state suppresses detection and public authority.

Polling reads published Page posts with stable post ID, trustworthy creation time, and canonical permalink. Personal profiles, timelines, Groups, comments, reactions, followers, private posts, and Facebook publishing are unsupported.
