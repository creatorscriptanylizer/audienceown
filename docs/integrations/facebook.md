# Facebook
Configure `FACEBOOK_*` and `/api/integrations/facebook/callback`. Connect Pages,
not personal profiles. Page list/read scopes and Meta app review are required.
Approved Page posts, videos, live events, permalinks, and thumbnails may use
polling/webhooks. Personal-profile scraping is unsupported.
Stage 8.3 supports selected managed Pages only. Personal profiles, timelines, and Groups are not automatic sources. Page authority and app-review readiness are shown separately.
